Mot de passe

1

Installer BlackHole 2ch

Pilote audio virtuel gratuit (open source). C'est lui qui permet à Teams/Zoom/Meet de "voir" la voix clonée comme un micro.

  1. Ouvrez la page officielle : existential.audio/blackhole
  2. Choisissez la variante BlackHole 2ch (gratuite).
  3. Saisissez votre email — un lien de téléchargement vous sera envoyé (instantané).
  4. Téléchargez le .pkg (~ 1 Mo) et double-cliquez dessus.
  5. Si l'installateur ne s'ouvre pas (Gatekeeper) : clic-droit → Ouvrir.
  6. Suivez les instructions. À la fin, BlackHole apparaît dans :
    🍎 → Réglages Système → Son → onglet Sortie / Entrée → "BlackHole 2ch"
  7. Vérification : ouvrez Audio MIDI Setup (/Applications/Utilities/Audio MIDI Setup.app) et confirmez que BlackHole 2ch est listé. Pas besoin de configuration manuelle.
💡 Alternative en ligne de commande (si vous avez Homebrew) : brew install --cask blackhole-2ch
2

Installer VoiceBridge.app

Application menu bar qui capture votre micro, l'envoie à voice.neorider.fr et joue la voix clonée dans BlackHole. L'URL du serveur est déjà intégrée dans le bundle.

📥 Télécharger VoiceBridge.app
  1. Décompressez le .zip téléchargé.
  2. Glissez VoiceBridge.app dans /Applications.
  3. Premier lancement : clic-droit → Ouvrir (Gatekeeper affichera "Apple ne peut pas vérifier", c'est normal pour une app non notarisée — confirmez "Ouvrir"). macOS s'en souvient pour les fois suivantes.
  4. macOS demande l'accès au micro → Autoriser. Si refusé : Réglages Système → Confidentialité → Microphone.
  5. Les Préférences s'ouvrent automatiquement avec l'URL déjà remplie. Collez votre clé API (cf. onglet API ci-dessus) et cliquez Tester + enregistrer.
  6. L'icône 🟢 apparaît dans la barre des menus en haut à droite — vous êtes connecté.
⚠️ Architecture supportée : Apple Silicon (M1/M2/M3/M4). Les Mac Intel ne sont pas couverts par ce build POC.
3

Configurer Teams / Zoom / Meet

Dites à votre app de visio d'utiliser BlackHole comme micro à la place de votre micro physique. VoiceBridge fait passer la voix clonée par là.

Microsoft Teams
… → Paramètres → Périphériques → Microphone → BlackHole 2ch
Zoom
⚙ → Audio → Microphone → BlackHole 2ch
Google Meet
⋮ → Paramètres → Audio → Microphone → BlackHole 2ch
macOS (système)
🍎 → Réglages Système → Son → Entrée → BlackHole 2ch
💡 Pour vérifier que tout fonctionne : Photo Booth → enregistrement vidéo, ou Mémo vocal → enregistrement. Vous devriez entendre votre voix clonée au lieu de votre voix réelle.
✓

Vérifier la chaîne complète

  • VoiceBridge.app affiche 🟢 dans la barre des menus
  • Cliquer dessus → Voix : juliette (ou la voix par défaut configurée)
  • Lancer un appel test (vous-même sur Teams + un autre compte)
  • Parler → la voix arrive dans Teams en cloné, latence ~0,7 à 1,5 s
  • Pour désactiver temporairement (zéro latence, voix réelle) : cliquer sur l'icône menu bar → ⏸ Mettre en pause.
