Mot de passe
1. Installer BlackHole 2ch

Pilote audio virtuel gratuit (open source). C'est lui qui permet à Teams/Zoom/Meet de "voir" la voix clonée comme un micro.

  1. Ouvrez existential.audio/blackhole.
  2. Choisissez BlackHole 2ch (gratuit) → saisissez votre email → recevez le lien.
  3. Téléchargez le .pkg (~ 1 Mo) et double-cliquez. Si bloqué : clic-droit → Ouvrir.
  4. Suivez l'installateur. À la fin, BlackHole apparaît dans :
    🍎 → Réglages Système → Son → onglet Sortie / Entrée
💡 Alternative Homebrew : brew install --cask blackhole-2ch
2. Installer VoiceBridge.app

Application menu bar qui capture votre micro et joue la voix clonée dans BlackHole. L'URL du serveur est déjà intégrée.

📥 Télécharger VoiceBridge.app
  1. Décompressez le .zip et glissez l'app dans /Applications.
  2. Premier lancement : clic-droit → Ouvrir (Gatekeeper, une seule fois).
  3. macOS demande l'accès au micro → Autoriser.
  4. Préférences s'ouvrent avec l'URL pré-remplie. Collez la clé API (onglet API ci-contre).
  5. Icône 🟢 dans la barre des menus = connecté.
⚠️ Architecture supportée : Apple Silicon (M1/M2/M3/M4) uniquement (V1).
3. Configurer Teams / Zoom / Meet

Microphone à choisir dans votre app de visio :

Microsoft Teams
… → Paramètres → Périphériques → Microphone → BlackHole 2ch
Zoom
⚙ → Audio → Microphone → BlackHole 2ch
Google Meet
⋮ → Paramètres → Audio → Microphone → BlackHole 2ch
macOS (système)
🍎 → Réglages Système → Son → Entrée → BlackHole 2ch
✓ Vérifier la chaîne complète
  • VoiceBridge.app affiche 🟢 dans la barre des menus.
  • Clic dessus → Voix : juliette (ou la voix par défaut configurée).
  • Lancer un appel test (vous-même sur Teams + un autre compte).
  • Parler → la voix arrive en cloné, latence ~0,7 à 1,5 s.
  • Pour désactiver temporairement (zéro latence, voix réelle) : clic icône menu bar → ⏸ Mettre en pause.
