Pourquoi Kaggle ?
L'entraînement RVC nécessite un GPU pendant 3-6 heures. Kaggle offre 30h de GPU gratuit/semaine (vérification téléphone requise). C'est la solution la plus accessible. Aucune donnée ne quitte ton compte Kaggle privé.
Étape 1 — Préparer le dataset
  1. Va dans Enregistrement guidé ou prépare ton ZIP de clips manuellement.
  2. Le wizard te guide à travers 5 blocs textes (~20 min audio total).
  3. Le retraitement automatique (~5 min) découpe en clips propres + génère le ZIP prêt pour Kaggle.
Étape 2 — Créer un compte Kaggle
  1. Va sur kaggle.com et crée un compte (gratuit).
  2. Vérifie ton numéro de téléphone — obligatoire pour accéder au GPU.
  3. Settings → Account → Phone verification.
Étape 3 — Forker le notebook RVC

Le notebook officiel "Applio RVC Trainer" est pré-configuré pour 300 epochs (~3h, qualité standard) ou 500 epochs (~6h, haute qualité).

🔗 Notebook Applio RVC Trainer
Étape 4 — Uploader ton dataset
  1. Sur Kaggle → "+ New Dataset"
  2. Drag & drop ton ZIP VoiceBridge (export depuis le wizard d'enregistrement).
  3. Nom : voicebridge-rvc-{ton-prenom}
  4. Visibilité : Privé
Étape 5 — Lancer l'entraînement
  1. Ouvre ton fork du notebook Applio.
  2. Settings → Accelerator : GPU T4 x2 (gratuit).
  3. "Add data" → ton dataset privé.
  4. Modifier la 1ère cellule : nom du modèle = {ton-prenom}_v1.
  5. Run All → attendre 3-6h. Reviens régulièrement (Kaggle déconnecte après 1h d'inactivité).
Étape 6 — Récupérer le modèle

À la fin du training, dans /kaggle/working/ :

  • model.pth (~150 Mo) — le modèle RVC
  • added_*.index (~50 Mo) — l'index FAISS (qualité +)

Télécharge les deux fichiers sur ton ordinateur.

+ Importer un .pth
